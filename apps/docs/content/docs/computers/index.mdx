A bot works on the computer running OpenMausBot: its shell and files there, the built-in browser, and, in the desktop app, this computer's own screen when a task needs desktop apps.

## Preview and takeover

The Computer panel can show live frames while an agent works.

When a bot needs you to sign in to a website, it asks with a **Sign in needed** card instead of asking for a password in chat. **Open** goes to the computer or browser the bot is working in, with **Take control**; **Done** hands it back and resumes the bot. See [Website sign-in](/docs/security/permissions-and-secrets#website-sign-in).

<Callout type="warn" title="Preview is not permission">
  Starting a screen preview does not grant the bot control. Local input requires a separate opt-in and remains subject to the computer-use safety boundary.
</Callout>
